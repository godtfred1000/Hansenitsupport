HANSEN IT SUPPORT – NETTSIDE

Slik tester du:
1. Pakk ut ZIP-filen.
2. Dobbeltklikk på index.html.

Før publisering:
1. Åpne js/script.js.
2. Bytt ut:
   DIN-EPOST@EKSEMPEL.NO
   DITT-TELEFONNUMMER
3. Endre prisene i priser.html dersom ønskelig.
4. Last opp hele innholdet til GitHub Pages eller webhotell.

Kontaktskjemaet åpner brukerens e-postprogram med en ferdig utfylt forespørsel.
Det kan senere kobles til Web3Forms dersom ønskelig.


BAKGRUNNSBILDER
Nettsiden bruker nå bakgrunnsbilder fra Unsplash direkte i css/style.css.
Søk etter teksten: Bakgrunnsbilder fra Unsplash

For maksimal trygghet kan bildene senere lastes ned og legges i assets-mappen.
